# 04. 专注与习惯养成

> 返回导航：[../PLAN.md](../PLAN.md) | 调研依据：[00-竞品调研.md](00-竞品调研.md)
>
> **价值**：中 · **成本**：M · **优先级**：中期（v1.5）

## 一、为什么做

TickTick 证明「番茄钟 + 习惯打卡」打包是强需求（免费版即含，且用户评价「genuinely useful」）；FocusBox、Any.do、Planny 都把番茄钟当核心卖点。Whim Todo 已落地「习惯打卡」，顺势扩展「番茄钟 / 专注计时」能形成「任务 → 专注 → 习惯 → 统计」的完整闭环，且与现有 `habit.ts`、`stats.ts` 强联动。

## 二、拟做功能

### 1. 番茄钟 / 专注计时
- 25 分钟专注 + 5 分钟休息的经典番茄钟；可自定义时长。
- 开始专注时可关联当前任务（「正在专注：写周报」）。
- 专注结束时记录一次「专注会话」（`focusSession`），关联任务 id + 时长。

### 2. 专注统计
- 今日 / 本周专注总时长、专注次数、最专注的时间段。
- 专注时长可并入「统计」视图（如热力图下方加「专注时长」条）。

### 3. 习惯里程碑（扩展现有 habit.ts）
- 现有习惯打卡只有 streak / 本周次数，扩展：
  - 「连续 N 天」里程碑提示（7 天 / 30 天 / 100 天）
  - 周完成率目标（如「每周至少 5 次」），达标提示
  - 习惯的月度趋势图（折线或热力）

## 三、技术方案

- **纯函数层先行**：
  - `src/lib/focus.ts`：番茄钟状态机（`start / pause / complete / reset`）+ 会话统计纯函数。
  - 扩展 `src/lib/habit.ts`：里程碑判断、周目标达成、月度趋势。
- **计时器**：用 `Date.now()` 差值 + `setInterval` 驱动，注意 `visibilitychange` 时暂停/校准（复用 B4 的经验）。
- **存储**：专注会话独立 key（如 `whim-todo:focus`），不污染 `todos`。
- **零新增依赖**。

## 四、验收标准

- 番茄钟可开始/暂停/完成，切换标签页后计时不漂移。
- 专注会话正确关联任务，统计视图能看到专注时长。
- 习惯里程碑纯函数可测（7/30/100 天），达标时有克制提示。
- `prefers-reduced-motion` 下计时器无动画；移动端触控目标 ≥44px。

## 五、与现有模块的关系

- 复用 `habit.ts` 的 streak 逻辑、`stats.ts` 的统计框架、`dates.ts` 的日期工具。
- 专注时长与任务完成数据一起进入「统计」视图，形成完整效率画像。
- 成就徽章（主题 3）可引用专注/习惯数据（如「累计专注 100 小时」）。
