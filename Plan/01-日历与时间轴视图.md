# 01. 日历与时间轴视图

> 返回导航：[../PLAN.md](../PLAN.md) | 调研依据：[00-竞品调研.md](00-竞品调研.md)
>
> **价值**：高 · **成本**：M · **优先级**：短期（v1.4）

## 一、为什么做

调研显示，2026 年「日历/时间轴视图」已成待办工具的标配（TickTick 的 day/3-day/week/month 视图、Things 3 的 `Upcoming` 7 天滚动、Structured 的时间轴 + `now line`）。Whim Todo 当前的「计划」视图只是按日期的列表，缺少「时间感」——用户看不到任务在时间上的分布，也难做「这一周忙不忙」的预判。

## 二、拟做功能

### 1. 周视图（时间轴）
- 7 列（周一到周日），每列按 `dueAt` 时间从上到下排列任务。
- 顶部展示本周已完成 / 待办 / 逾期的概览（复用现有 `stats.ts`）。
- 「今天」列高亮，并有 `now line`（当前时间指示线，对标 Structured）。

### 2. 月视图
- 月历网格，有任务的日子显示圆点或数量角标（对标 Memos 的日历页）。
- 点击某天 → 查看/快速添加当天任务。
- 支持回看历史月份（呼应「记得住、找得回」定位）。

### 3. 拖拽排期（可选，后期）
- 把任务从「收件箱」拖到周视图某天/某时间块，自动设置 `dueAt`。
- 注意：必须提供键盘等价操作（WCAG 拖拽替代要求，复用 A1 的按钮方案）。

## 三、技术方案

- **纯函数层先行**：新增 `src/lib/calendar.ts`，提供 `buildWeekView(todos, weekStart)` / `buildMonthView(todos, month)` 纯函数，复用 `dates.ts` 的 `startOfWeek` / `startOfDay` 等工具。
- **视图接线**：扩展 `View` 类型，加「周」「月」两个视图入口，或做成「计划」视图内的子切换（segmented：列表 / 周 / 月）。
- **零新增依赖**：日历渲染用纯 CSS Grid（7 列布局），不引日期库。

## 四、验收标准

- 周视图能看到任务按时间分布，今天列高亮，`now line` 随真实时间移动。
- 月视图能回看任意历史月份，点击日期能看当天任务。
- 键盘可完成「切周/月视图 → 选中某天任务 → 打开」全流程。
- 375 / 768 / 1440px 无横向滚动，移动端周视图可横向滚动或折叠为「今日列表」。

## 五、与现有模块的关系

- 复用 `stats.ts` 的概览数据、`dates.ts` 的日期工具、`weeklyExport.ts` 的周报。
- 与「统计」视图联动：周视图顶部概览卡可直接复用 StatsView 的概览卡组件。
- 不破坏 `file://` 单文件构建（纯前端实现）。
