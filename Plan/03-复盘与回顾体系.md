# 03. 复盘与回顾体系

> 返回导航：[../PLAN.md](../PLAN.md) | 调研依据：[00-竞品调研.md](00-竞品调研.md)
>
> **价值**：高 · **成本**：M · **优先级**：短期（v1.4）

## 一、为什么做

复盘是「记得住、找得回」的核心价值，也是调研中反复出现的留存关键：flomo 的每日回顾、SelfManager 的 date-centric 周/月回顾、TickTick 的年度视图、Things 3 的周回顾。Whim Todo 已有「每日回顾」（抽 3 条旧备忘）+「周报导出」（统计），但缺少**周/月/年度的可视化复盘**和**成就感反馈**。

## 二、拟做功能

### 1. 周复盘（升级现有周报）
- 现有 `weeklyExport.ts` 只下载 Markdown，升级为**在统计视图内可视化展示**：
  - 本周完成数 vs 上周完成数（环比，涨跌用主题色区分）
  - 本周逾期数、主要完成标签 Top 3
  - 一条「本周亮点」小结（模板化文案，未来可接 AI）
- 保留 Markdown 导出，但增加「周复盘卡片」内嵌展示。

### 2. 月度复盘
- 月视图 + 月度统计：本月完成数、连续打卡最佳 streak、活跃标签变化。
- 对比上月，给出趋势（上升/下降）。

### 3. 年度回顾（长期）
- 「我的这一年」：累计完成 X 条、最长连续打卡 X 天、最常用标签、记忆最多的月份。
- 对标 TickTick 年度视图；成本高，放后期。

### 4. 成就徽章（轻量激励）
- 纯前端、零依赖的成就系统：如「连续 7 天打卡」「单日完成 10 项」「记录 100 条备忘」等。
- 纯函数层 `src/lib/achievements.ts`，按数据计算达成哪些徽章。
- 对标 Todoist Karma / Planny XP，但克制——不做排行榜、不做社交。

## 三、技术方案

- **纯函数层**：`src/lib/review.ts` 已存在（每日回顾），扩展 `weeklyRecap` / `monthlyRecap` / `achievements`。
- **复用**：`stats.ts` 的统计、`habit.ts` 的 streak、`dates.ts` 的周期工具。
- **零新增依赖**，全部纯前端计算。

## 四、验收标准

- 统计视图能看到「本周 vs 上周」环比，涨跌颜色符合主题（复用 token）。
- 月度复盘能回看任意历史月份。
- 成就徽章纯函数可测，达成条件触发时在界面有提示（克制、不打扰）。
- 门禁：265+ tests 全绿，lint 0 error，build 通过。

## 五、与现有模块的关系

- 与「统计」视图强联动，可作为统计视图的子 Tab（周 / 月 / 年）。
- 与「习惯打卡」联动（best streak、连续打卡成就）。
- 与「每日回顾」形成完整闭环：日回顾 → 周复盘 → 月复盘 → 年度回顾。
